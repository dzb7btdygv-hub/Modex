# Modex Brand Assets

These assets are original Modex branding. Do not use OpenAI logos, Codex logos, or official-looking OpenAI marks in Modex materials.

- `modex-mark.svg`: standalone app mark
- `modex-wordmark.svg`: README/header wordmark with the mark as the M
- `modex-readme-header.svg`: wide GitHub/social preview source
- PNG files are rendered copies for places that do not support SVG well.
