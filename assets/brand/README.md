# Modex Brand Assets

These assets are original Modex branding. Do not use OpenAI logos, Codex logos, or official-looking OpenAI marks in Modex materials.

- `modex-mark-transparent.png`: transparent gradient mark
- `modex-mark-source-crop.png`: exact extracted mark from the source logo
- `modex-mark-on-light.png`: gradient mark on a light surface
- `modex-mark-on-dark.png`: gradient mark on a dark surface
- `modex-mark-black.png`: single-color mark for light surfaces
- `modex-mark-white.png`: single-color mark for dark surfaces
- `modex-wordmark.png`: transparent stacked lockup
- `modex-readme-header.png`: wide GitHub README/social banner
- `modex-logo-source.png`: source logo reference used to produce the exported assets
